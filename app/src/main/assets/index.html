Come funziona CIMG v1

Un codice ottico temporale con 16 colori = 4 bit per cella. I primi 16 simboli calibrano i colori per ogni fotogramma; un bordo ad alto contrasto aiuta il rilevamento.

CODE_START → primo frammento (bit 0)
DATA → fotogrammi numerati con ID sessione
CODE_END → ultimo frammento (bit 1)
CRC32 → controllo del singolo frammento e dell'intero stream
.cimg → contenitore binario con metadati + dati zlib
GIF → animazione ripetuta della stessa sequenza
Codifica → 2 celle per byte; protocollo aperto documentato nel README

Formato sperimentale: non è un QR standard e richiede lo scanner CodexAnim. La capacità teorica non è una garanzia di velocità reale: inquadrare un display con il telefono introduce perdita di fotogrammi, prospettiva, riflessi e differenze cromatiche.
